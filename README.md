# FB入金データ生成ツール

デモ用の全銀協フォーマット準拠の入金FBデータファイルを生成するWindowsデスクトップGUIツールです。

## 概要

銀行振込入金明細のFBデータ（全銀協フォーマット）をCSVファイルから生成します。出力ファイルはShift-JIS・200バイト固定長レコード・CRLF改行のテキストファイルです。

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | React 19 + TypeScript + Vite |
| バックエンド | Rust (Tauri v2 コマンド) |
| デスクトップ | Tauri v2 |
| スタイリング | Tailwind CSS |
| フォーム管理 | react-hook-form + zod |

## 機能

- **ヘッダー情報入力**：入金日・銀行コード・銀行名・支店コード・支店名・預金種目・口座番号をGUIで入力
- **CSV読み込み**：Shift-JIS形式の入金明細CSVを読み込み、内容をプレビュー表示
- **バリデーション**：フロントエンド（即時）・バックエンド（CSV読み込み時）の2段階検証
- **FB生成**：全銀協フォーマット準拠のFBデータファイルを出力（ヘッダー・データ・トレーラー・エンドレコード）

## 入力CSVフォーマット

ヘッダー行あり・文字コードShift-JIS

```
金額,銀行名(カナ),支店名(カナ),摘要文字列,EDI
100000,トウキヨウギンコウ,シンジユクシテン,カブシキガイシャサンプル,
```

| フィールド | 型 | 制約 |
|---|---|---|
| 金額 | 整数 | 1以上・12桁以内 |
| 銀行名(カナ) | 文字列 | 半角カタカナ・半角英数字・15文字以内・空欄可 |
| 支店名(カナ) | 文字列 | 半角カタカナ・半角英数字・15文字以内・空欄可 |
| 摘要文字列 | 文字列 | 半角カタカナ・半角英数字・48文字以内 |
| EDI | 文字列 | 20文字以内・空欄可 |

## 出力FBデータ仕様

- **文字コード**：Shift-JIS
- **レコード長**：200バイト固定
- **改行コード**：CRLF
- **レコード構成**：ヘッダーレコード（1件）+ データレコード（明細件数分）+ トレーラーレコード（1件）+ エンドレコード（1件）

## 開発環境セットアップ

### 前提条件

- [Rust](https://www.rust-lang.org/tools/install) (最新stable)
- [Node.js](https://nodejs.org/) (v18以降)
- [Tauri CLI v2](https://v2.tauri.app/start/prerequisites/)

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run tauri dev
```

### ビルド（単一exe生成）

```bash
npm run tauri build
```

`src-tauri/target/release/bundle/` 配下に `.exe` が生成されます。
