# FB入金データ生成ツールについて

## ① ツールを作成した背景

MJSLINKの入金管理やGalileoptの債権管理の商談・デモ、動作検証では、全銀協フォーマット準拠の入金FBデータ（振込入金明細・入出金明細）が必要になる。

これまでは対象のFBデータをテキストエディタ等で手作業で作成しており、以下の課題があった。

- 全銀協フォーマットは項目ごとの桁数・ゼロパディング／スペースパディング・文字コード（Shift-JIS）などの規則が細かく、手作業では時間がかかりミスが起きやすい
- 商談・デモの担当者（営業・CS）が都度エンジニアにFBデータ作成を依頼する必要があり、準備に手間がかかっていた

これらを解消し、専門知識がなくてもGUI操作だけで正しいFBデータを短時間で作成できるようにするため、本ツールを開発した。

## ② 具体的なツールの内容

Windows向けのデスクトップGUIツール（単一の`.exe`、インストール不要）。

- **技術構成**：Tauri v2 + React（TypeScript）+ Rust
- **対応FB種別**（画面上部のタブで切替）
  - 振込入金明細（種別コード01）
  - 入出金明細（種別コード03）
- **操作の流れ**
  1. 画面左側でヘッダー情報（入金日・銀行コード／名・支店コード／名・預金種目・口座番号）を入力（JSON形式での入出力にも対応し、毎回の再入力を省略可能）
  2. 明細データをCSV（Shift-JIS）として読み込み、画面上でプレビュー確認
  3. 「FBデータを生成」ボタンで出力先を指定し、全銀協フォーマット準拠のFBデータファイルを生成
- **バリデーション**：入力値・CSVそれぞれに対してフロントエンド／バックエンドの2段階でチェックし、フォーマット不備を事前に検出
- **出力仕様**：Shift-JIS、200バイト固定長レコード、CRLF改行（ヘッダー・データ・トレーラー・エンドレコードで構成）
- アプリ内の「マニュアルを開く」ボタンから、同梱のユーザーマニュアル（HTML）をいつでも参照可能

## ③ 期待と効果

- 商談・デモ・動作検証の準備時間を短縮（CSVを用意するだけで数秒〜数十秒でFBデータを生成）
- フォーマット不備によるデモ当日のトラブルや手戻りを、バリデーション機能により事前に防止
- 営業・CSなど非エンジニアの担当者が、エンジニアに依頼することなく自分でFBデータを用意できるようになり、依頼待ちのタイムロスを削減
- 振込入金明細に加えて入出金明細にも対応したことで、Galileoptの債権管理デモなど、より幅広いシナリオの動作検証をカバー

## ④ 利用頻度

月に数回程度。商談・デモ、動作検証が発生するタイミングで都度利用されている。

## ⑤ 生成AIが担えている割合

ほぼ全体（実装コードベースでおおむね100%相当）。仕様の要件整理・確認・最終レビューは担当者が行っているが、Rustバックエンド・Reactフロントエンド・テストコード・ドキュメント（本回答含む）の実装は、Claude Codeによる生成AIが担当している。

## ⑥ ツールの共有状況

Sol中部内で、債権管理／入金管理の導入・商談を行っている営業・CSに共有している。
